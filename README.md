# מתכנן המטבח – משפחת עובדיה

עורך מטבח אינטראקטיבי (אופציה ב׳ מתוכנית מירי אזולאי). אתר סטטי: HTML/CSS/JS בלי שלב בנייה.
three.js r160 כלול בתיקייה vendor.

- תוכנית מבט-על עם גרירה, הצמדה, החלפת מקומות בין ארונות ומעבר בין קירות
- חזיתות לכל קיר, תלת-ממד פשוט/ריאליסטי, רשימת ארונות ונקודות חשמל/מים
- שמירה אוטומטית בדפדפן, ייצוא/ייבוא JSON, הדפסה ל-PDF

מערכת צירים: x ימינה (0 = צד הכניסה), y למטה (0 = קיר המקרר), בדיוק כמו בתוכנית. בתלת-ממד X = x, Z = y, בלי שיקוף.

## תכנון אדריכלי (arch.html)
מצב לכל הדירה: העלאת תוכנית (PDF/תמונה), כיול קנה מידה (1:N או שתי נקודות), זיהוי אוטומטי של קירות/חדרים/דלתות (בעיקר ב-PDF וקטורי), עריכת חדרים (מלבן, מצולע, פיצול, עריכת נקודות), דלתות וחלונות, מחולל העמדות מבוסס-חוקים (3–5 חלופות לחדר), קטלוג רהיטים במידות אמיתיות עם גרירה/סיבוב/שינוי מידה/הצמדה לקירות ובדיקות התנגשות ומעברים, תלת-ממד (three.js) בלי שיקוף, שמירה בדפדפן, ייצוא/ייבוא JSON, הדפסה.
קבצים: `arch.html`, `css/arch.css`, `js/arch/*` (geom, data, detect, generate, plan, view3d, app), `vendor/pdfjs`, `samples/` (הפרויקט המוכן מהתוכנית).
